# 🔎 GitHub User Search

A modern GitHub profile explorer built with **React 19**, **Vite**, **TypeScript**, **GraphQL**, and the **GitHub GraphQL API**. Search for GitHub users and explore detailed profile information, repositories, contribution statistics, and activity through a clean, responsive interface.

## ✨ Features

- 🔍 Search GitHub users by username
- 👤 View detailed user profiles
- 📊 Repository and contribution statistics
- 📈 Interactive charts with Recharts
- 🌙 Light & Dark mode
- ⚡ Fast GraphQL data fetching with Apollo Client
- 📱 Responsive design
- 🎨 Modern UI built with Tailwind CSS and shadcn/ui
- 🔔 Toast notifications with Sonner
